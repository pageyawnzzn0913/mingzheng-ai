# 明证 AI 一键部署版本

## 本地运行
```bash
npm install
npm run dev
```

## 构建
```bash
npm run build
```

## 部署到 Vercel
1. 上传本项目到 GitHub。
2. 在 Vercel 选择 New Project。
3. 导入 GitHub 仓库。
4. Framework Preset 选择 Vite。
5. Build Command: `npm run build`
6. Output Directory: `dist`
7. 点击 Deploy。

## 说明
这是纯前端 Demo，不包含真实后端账号系统、数据库、支付或审核后台。
